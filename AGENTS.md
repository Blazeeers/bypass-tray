# AGENTS.md — инструкция для агента на Windows

Коротко: это Windows-трей-приложение на Python (pystray + Tkinter), которое
показывает статус обходов (Xray-прокси, zapret/winws, tg-ws-proxy), управляет
ими и уведомляет об обновлениях. Приложение развёрнуто и проверено; VPN
работает на собственном ядре Xray, сторонние клиенты не используются.
Полное ТЗ — [docs/SPEC.md](docs/SPEC.md).

## Быстрый старт

```bat
install.bat
run.bat
```

Проверка без GUI:

```bat
.venv\Scripts\python.exe -m bypass_tray --status
.venv\Scripts\python.exe -m bypass_tray --health
.venv\Scripts\python.exe -m bypass_tray --route-audit [--apply]
.venv\Scripts\python.exe -m bypass_tray --updates
```

Дымовые проверки (ничего не останавливают и не запускают):

```bat
.venv\Scripts\python.exe tests\smoke_test.py
```

По умолчанию набор офлайн (сетевые пункты — `SKIP`); включить сеть:
`BYPASS_TRAY_LIVE=1`.

Конфиг: `%APPDATA%\bypass-tray\config.json` (пути к zapret/tg-ws-proxy, подписка
и порт Xray, `theme`: `auto`/`light`/`dark`, `quiet_icon`, `guard_enabled`,
`guard_minutes`, `health_minutes`, `route_audit_minutes`, `autoconnect`,
`xray_routes` — пользовательские маршруты сайтов, `blocked_list_enabled` —
встроенный список Re:filter).
Служебные файлы рядом: `activity.json`, `health.json`, `route_overrides.json`,
`networks.json`, `xray.log`, `xray-*.json`.

## Что уже сделано

1. Автопоиск путей zapret и tg-ws-proxy: вложенные папки, типовые каталоги,
   ограниченный поиск по дискам.
2. Определение стратегии: отпечаток опций `--dpi-desync*`; при установке
   службой аргументы читаются из реестра — права администратора не нужны.
3. Потокобезопасность панели: один интерпретатор Tk, команды через очередь,
   действия в отдельных потоках.
4. Оповещения: запасное мигание иконки, если `icon.notify` подавлен.
5. Интерфейс: карточки, индикаторы, светлая/тёмная тема, иконки трея с
   галочкой/буквами (см. `docs/img/`).
6. Определение кодировки вывода `sc.exe`/`tasklist` (cp866 на русской Windows).
7. **Автоподбор стратегии zapret** (`strategy.py`): перебор `general*.bat` с
   реальной проверкой YouTube/Discord, установка лучшей в службу. Команда
   берётся запуском копии `.bat` с `start`→`echo` (совпадает с командой
   службы 50/50 токенов). Запуск — отдельным процессом с UAC.
8. **Собственный VPN-клиент Xray** (`xray.py`): подписка, проверка серверов,
   выбор самого быстрого, локальный mixed-прокси на `127.0.0.1:10818`, системный
   прокси, сплит-туннель правилами маршрутизации, авто-переключение сервера
   при отказе, резервный режим YouTube/Discord без zapret.
9. **Интерфейс 0.3.0** (`ui.py`, `settings_ui.py`, `widgets.py`, `icons.py`):
   шапка состояния, карточка VPN со списком серверов (`★` лучший, `●` текущий),
   пять строк сервисов, обновления, журнал действий, тумблеры поведения,
   прокрутка тела, кэш иконок; тёмная системная рамка окна; настройки с секцией
   «Поведение», применяемой сразу.
10. **Проверки, надзиратель, маршруты** (`health.py`, `guard.py`, `routes.py`):
   настоящие health-пробы (страницы, CDN, шлюз, Bot API через прокси, порт,
   `xray.verify()`), guard без UAC, аудит доменов с direct/proxy-оверрайдами и
   применением из панели по подтверждению.
11. **Память стратегии по сети** (`networks.py`): ключ MAC/шлюз/SSID, запись
   после автоподбора, применение при смене сети (проверка раз в минуту).
12. **Обновления и журнал** (`updates.py`, `activity.py`, `autostart.py`):
   zapret, tg-ws-proxy и Xray-core, «Обновить всё» с атомарными загрузками,
   журнал последних 60 действий, ярлык автозапуска.
13. **Записи**: конфиг, состояние и служебные JSON пишутся атомарно; битый
    `config.json` переименовывается и не перезаписывается. Дымовой набор —
    381 проверка.
14. **Пользовательские маршруты сайтов** (`settings_ui.py`, `routes.py`,
    `xray.py`): раздел «Маршруты сайтов» в настройках, `xray_routes` в
    конфиге, приоритет над автоподбором и встроенными списками, миграция
    старых `xray_direct_domains`/`xray_extra_domains`.
15. **Список заблокированных сайтов** (`blocked.py`, `data/`): Re-filter-lists
    (REFILTER, ≈81 тыс. доменов / 81 395 записей, MIT), копируется в `bin` и подключается правилом
    `ext:…:REFILTER`; включён по умолчанию, обновляется из настроек.

## Что осталось

1. **Single-instance** реализован мьютексом
   `Local\Blazeeers.BypassTray` для GUI; CLI не блокируется.
2. **Самообновление виджета** не делаем; версия читается из `pyproject.toml`
   (`updates.widget_version()`), но отдельной строки в UI нет.
3. **Живые UAC-действия** (управление службой zapret, автоподбор) и живой
   перебор стратегий в этом этапе не запускались — берегли рабочий обход.
4. **Реальный обрыв сервера** не устраивался: автопереключение проверено
   логикой и тестами с заглушками.
5. **TUN невозможен** — ограничение (конфликт с zapret/WinDivert); VPN только
   локальный прокси `127.0.0.1:10818`.

## Заметки

- Код в `src/bypass_tray/`; после правок проверяй
  `.venv\Scripts\python.exe -m compileall src tests`.
- UI-модули: `ui.py` (панель), `settings_ui.py` (настройки), `widgets.py`
  (Canvas-виджеты), `theme.py` (схемы), `icons.py` (иконки трея и панели).
- Фоновая логика: `health.py` (проверки), `guard.py` (надзиратель),
  `routes.py` (аудит и оверрайды), `networks.py` (стратегия по сети),
  `activity.py` (журнал), `autostart.py`, `updates.py`, `components.py`,
  `blocked.py` (список Re:filter).
- Данные: `data/geosite-refilter.dat` + `data/README.md`; при запуске
  копируется в `bin` (сам `bin/` в git не хранится). Лицензии сторонних
  материалов — `THIRD_PARTY.md`.
- Сборка `.exe`: `packaging/` есть в ветке; spec включает `bin`, `data`,
  `LICENSE`, `THIRD_PARTY.md`, `version_info.txt` (0.6.3) и ONEDIR
  `contents_directory="."`; подробности — README «Сборка .exe».
- Не коммить `.venv/`.
- Если меняешь автопоиск путей — обнови [docs/CONFIG.md](docs/CONFIG.md).
- Xray работает в режиме локального прокси и НЕ включай TUN: он конфликтует
  с zapret (WinDivert). Проверка туннеля — только через прокси `10818`.
- Guard не перезапускает Xray и не вызывает UAC; применение маршрутов с
  перезапуском — только кнопка панели после подтверждения.
- Скриншоты панели для документации удобно снимать так же, как это делалось:
  собрать панель в своём `tk.Tk()`, вызвать `_build`, затем `ImageGrab`.
