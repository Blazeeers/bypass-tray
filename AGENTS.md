# AGENTS.md — инструкция для агента на Windows

Коротко: это Windows-трей-приложение на Python (pystray + Tkinter), которое
показывает статус обходов (Happ, zapret/winws, tg-ws-proxy), управляет ими и
уведомляет об обновлениях. Приложение развёрнуто и проверено; открытым
остаётся сплит-туннель Happ. Полное ТЗ — [docs/SPEC.md](docs/SPEC.md).

## Быстрый старт

```bat
install.bat
run.bat
```

Проверка без GUI:

```bat
.venv\Scripts\python.exe -m bypass_tray --status
```

Дымовые проверки (ничего не останавливают и не запускают):

```bat
.venv\Scripts\python.exe tests\smoke_test.py
```

Конфиг: `%APPDATA%\bypass-tray\config.json` (пути к zapret/tg-ws-proxy/Happ,
`theme`: `auto`/`light`/`dark`).

## Что уже сделано

1. Автопоиск путей: вложенные папки, вендорские каталоги Happ
   (`Program Files\FlyFrogLLC\Happ`), ограниченный поиск по дискам.
2. Определение стратегии: отпечаток опций `--dpi-desync*`; при установке
   службой аргументы читаются из реестра — права администратора не нужны.
3. Потокобезопасность панели: один интерпретатор Tk, команды через очередь,
   действия в отдельных потоках.
4. Оповещения: запасное мигание иконки, если `icon.notify` подавлен.
5. Интерфейс: карточки, индикаторы, светлая/тёмная тема, иконки трея с
   галочкой/буквами (см. `docs/img/`).
6. Определение кодировки вывода `sc.exe`/`tasklist` (cp866 на русской Windows).
7. **Автоподбор стратегии zapret** (`strategy.py`): перебор `general*.bat` с
   реальной проверкой YouTube/Discord, установка лучшей в службу. Команда
   берётся запуском копии `.bat` с `start`→`echo` (совпадает с командой
   службы 50/50 токенов). Запуск — отдельным процессом с UAC.
8. **Туннелирование Happ** (`happ.py`): профили «Обходы»/«Обходы (резерв)»,
   включение через реестр (`useRouting` и др.), проверка связи с автооткатом,
   резервный профиль по падению zapret/tg-ws-proxy.

## Что осталось

1. **Живая проверка туннеля Happ.** При первой попытке YouTube/Discord дали
   ошибку TLS, Instagram/Facebook не открылись, связь оборвалась; настройки
   отката возвращены. Нужно понять, мешает ли TUN-режим Happ работе zapret.
   Подробности и варианты — [docs/HAPP-ROUTING.md](docs/HAPP-ROUTING.md).
2. **Живой перебор стратегий** не запускался: он ~1,5 минуты держит обход
   выключенным. Запускать кнопкой «Подобрать лучшую стратегию» (нужен UAC).
3. Проверить кнопки управления службой zapret вживую (нужен UAC).

## Заметки

- Код в `src/bypass_tray/`; после правок проверяй
  `.venv\Scripts\python.exe -m compileall src tests`.
- UI-модули: `ui.py` (панель), `widgets.py` (Canvas-виджеты), `theme.py`
  (схемы), `icons.py` (иконки трея).
- Не коммить `.venv/`.
- Если меняешь автопоиск путей — обнови [docs/CONFIG.md](docs/CONFIG.md).
- Включение туннеля Happ меняет всю сеть машины: не тестируй его, не убедившись,
  что автооткат сработает (метка `happ-activation.pending.json`).
- Скриншоты панели для документации удобно снимать так же, как это делалось:
  собрать панель в своём `tk.Tk()`, вызвать `_build`, затем `ImageGrab`.
