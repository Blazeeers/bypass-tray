# Встроенный список заблокированных сайтов

В этой папке лежит очищенный список доменов, заблокированных в РФ, в формате
geosite для ядра Xray.

| Что | Значение |
|---|---|
| Файл | `geosite-refilter.dat` |
| Категория | `REFILTER` |
| Источник | [1andrevich/Re-filter-lists](https://github.com/1andrevich/Re-filter-lists) |
| Релиз | `geosite.dat` (последний) |
| Домены | ≈81 тыс. (в файле 81 395 записей; исходный текстовый список — 81 061 домен) |
| Дата набора | 19.10.2026 (тег `19102026`) |
| Лицензия | MIT, см. [LICENSE-refilter.txt](LICENSE-refilter.txt) |

При первом запуске файл копируется в `bin` рядом с ядром Xray
(`blocked.ensure()`), и в конфиг добавляется правило:

```
{"type": "field", "outboundTag": "proxy", "domain": ["ext:geosite-refilter.dat:REFILTER"]}
```

## Что это меняет

- Заблокированные домены из списка идут **через VPN**.
- **YouTube и Discord** остаются **напрямую под zapret**, когда он работает;
  в резервном режиме (zapret остановлен) они уходят в туннель — правило
  `direct` для `xray.STREAM_DOMAINS` есть только пока резервный режим выключен.
- **Свои правила** («Маршруты сайтов») и **аудит direct** стоят выше списка:
  если сайт явно отправлен напрямую, список его не перебивает.
- Список не добавляется в исключения системного прокси: он влияет только на
  маршрутизацию внутри Xray.

## Как обновить

- В окне «Настройки» → «Список заблокированных сайтов» → «Обновить список».
  Файл скачивается из релиза Re-filter-lists, проверяется разбором
  GeoSiteList и `xray.exe -test`, затем атомарно подменяется в `bin`;
  после этого прокси перезапускается (если был подключён).
- Отключить список можно тумблером «Использовать список Re:filter» в той же
  секции. Настройка хранится как `blocked_list_enabled` в `config.json`.

## Как пересобрать вручную

1. Возьмите `geosite.dat` из релиза
   [Re-filter-lists](https://github.com/1andrevich/Re-filter-lists/releases).
2. Положите его как `bin/geosite-refilter.dat` (категория внутри должна быть
   `REFILTER`).
3. Либо замените `data/geosite-refilter.dat` и удалите копию в `bin` — при
   следующем запуске `ensure()` скопирует файл заново.

Если `data/` в сборке нет, `ensure(auto_download=True)` попробует скачать
список при первом подключении; повторная попытка — не чаще раза в час
(`last_attempt` в `blocked-list.json`).

## Сборка .exe

При упаковке в PyInstaller обязательно включать каталог `data/` вместе с
`data/LICENSE-refilter.txt`, иначе встроенный список не попадёт в сборку:

```python
datas=[(r"data", "data")]
```

В этой ветке каталога `packaging/` нет — шаг нужно выполнить вручную при
публикации сборки. Если `data/` забыли, `blocked.ensure(auto_download=True)`
попробует скачать список при первом подключении (не чаще раза в час).

Проверка конфига без запуска: `bin\xray.exe -test -c <файл конфига>`.
